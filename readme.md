# ProjectPROMO

[日本語](readme.md) | [English](README.en.md) | [繁體中文](README.zh-TW.md)
**AI と一緒に制作。コンテンツをまとめて、複数のプラットフォームへ配信。**

ProjectPROMO は、AI を活用した SNS 宣伝のためのワークスペースです。ブランド情報、文章、画像、動画を Content Sheet にまとめ、人が確認してから予約投稿し、各プラットフォームの投稿状況と成果を一元管理できます。

現在はローカルで動作する **単一ワークスペースの試験版** です。長期的には SaaS を目指していますが、本番のマルチテナントサービスに必要なアカウント分離、権限管理、課金機能はまだありません。

## ワークフロー

```text
ブランドのコンテキスト + AI との対話
           ↓
Content Sheet（下書きを自動保存）
           ↓
人によるレビュー → 今すぐ投稿 / 予約投稿
           ↓
プラットフォーム別の配信ジョブ → 状態・投稿 ID・URL
           ↓
データ同期 → ダッシュボード
```

1 枚の Sheet に共通のコンテンツを保存し、複数の配信先を選べます。プラットフォームごとに文章を変える場合は、Sheet を複製して編集します。

## 実装済みの機能

- **AI 制作チャット**：自分の DeepSeek API キーを使って、下書きの作成・取得・編集・複製ができます。モデル ID も設定可能です。
- **ブランドの常駐コンテキスト**：ブランドの位置づけ、語り口、製品情報を保存し、以後の制作に利用します。
- **コンテンツ編集**：タイトル、本文、タグ、メディア、配信先、投稿時刻を編集できます。自動保存、バージョン確認、取り消し、参考プレビューに対応しています。
- **人によるレビュー**：一括承認後、変更不可の投稿スナップショットを作成します。AI に直接承認・投稿するツールはありません。
- **配信管理**：プラットフォームごとに成功・失敗を管理します。結果が不明な場合は手動で確認し、無条件の再試行による重複投稿を防ぎます。
- **ダッシュボード**：各プラットフォームから取得した指標のスナップショットを保存します。未取得の指標は空欄とし、架空の成果は表示しません。

## 対応プラットフォーム

| プラットフォーム | 接続方法 | 実装済みの投稿インターフェース |
| --- | --- | --- |
| X | OAuth 2.0 PKCE または User Access Token | テキスト・画像・動画 |
| Facebook Page | Page Access Token | テキスト・画像・動画 |
| Threads | Threads User Access Token | テキスト・JPG/PNG・複数画像・MP4 1 本 |
| Instagram | Instagram Login Token、プロアカウント | JPG・最大 4 枚の画像・MP4 Reel 1 本 |

実装済みでも、すべてのアカウントで利用できるとは限りません。プラットフォームの権限、メディア仕様、利用枠、審査に依存します。取得できる指標もプラットフォームごとに異なります。Threads／Instagram は一部のフローを模擬 API でテスト済みですが、実アカウントでのエンドツーエンド検証は未完了です。

## クイックスタート

Node.js 20.19 以上と npm が必要です。

```powershell
npm ci
Copy-Item .env.example .env
```

`.env` を編集し、`ADMIN_PASSWORD` を自分の長いパスワードに変更してください。DeepSeek と SNS のトークンは、ログイン後の「品牌與連接」（ブランドと接続）で設定します。X OAuth の Client ID、Secret、Callback は `.env` で設定します。

```powershell
npm run build
npm start
```

[ローカルワークスペース](http://127.0.0.1:4100/) を開きます。同じローカルデータベースを共有するバックエンドを複数同時に起動しないでください。

開発時は `npm run dev` を使います。フロントエンドの開発用 URL は `http://127.0.0.1:5173/` です。検証コマンド：

```powershell
npm run check
```

## メディア投稿と公開 URL

X／Facebook のインターフェースは素材を直接アップロードします。Threads／Instagram では、現在 Meta が HTTPS URL からローカル素材を取得するため、次の設定が必要です。

```dotenv
MEDIA_PUBLIC_BASE_URL=https://your-media-host.example
```

`server/media-gateway.mjs` は、素材の読み取りのみを受け付けるローカルプロキシをポート 4101 で提供します。独自の HTTPS リバースプロキシやトンネルに接続できます。素材 URL は署名付きで、24 時間後に失効します。有効なリンクを持つ人は素材を閲覧できます。管理画面を直接インターネットへ公開しないでください。

`npm start` ではトンネルは自動起動しません。一時トンネルの URL が変わった場合は、環境設定を更新してサービスを再起動してください。プラットフォームが素材を取得している間は、サービスとトンネルの両方を稼働させる必要があります。

## 技術スタック

- React、TypeScript、Vite
- Node.js、Express、Zod
- PostgreSQL（既定ではローカルの PGlite）
- SQL ジョブキュー、各プラットフォームの API アダプター
- DeepSeek のツール呼び出し、ローカルメディア保存、AES-256-GCM による認証情報の暗号化

## 現在の制限

- ローカルの単一管理者向けです。マルチテナント対応、安全な本番運用環境、SaaS 課金は未完成です。
- 画像・動画は手動で追加します。生成サービス向けのインターフェースは用意していますが、実際の生成サービスには未接続です。
- ブランドのコンテキストは実装済みですが、製品 RAG ナレッジベースは未実装です。
- Facebook／Threads／Instagram のトークンは手動管理が必要です。X OAuth は更新に対応しています。
- SNS の API は有料の場合があり、それぞれ認可条件や利用制限があります。このプロジェクトは無料の API 利用枠を提供しません。
- Computer Use による投稿実行機能は未実装です。
- API が投稿を受け付けても、すぐに一般公開されるとは限りません。プラットフォーム上で結果を確認してください。
